JSON fields and setup help

Each game: date, time, away, home, winner, winProbability (0–1), scoreAway, scoreHome, rating, optional moneyline/spread/total and notes. For Monday night set mondayTiebreaker to an integer. Results may include games with predictedWinner, actualWinner, predictedTotal and actualTotal.

Host these files on an HTTPS site, open in Safari, choose Share → Add to Home Screen.
